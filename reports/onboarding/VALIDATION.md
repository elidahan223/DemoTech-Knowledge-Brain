# אימות מדריך ההתקנה — 08.11.2026

- זוהו scripts אמיתיים ב־package.json, כל משתני הסביבה שבקוד שרת/Desktop, מדיניות loopback, נתיבי אחסון ותהליך seed. תיעוד רשמי של Node, Ollama, Git ו־VS Code נבדק לקישורי הורדה ולדרישות.

- נוצר עותק מקור מבודד ללא data, מסמכי seed או מסד קיים, והועתק אליו `.env.example`. התלויות הקיימות שותפו באמצעות junction; **לא בוצע npm ci חדש או אימות הורדות**.
- בעותק עברו `tsc --noEmit`, בניית Vite ו־`node scripts/build-desktop.mjs`. ההפעלה המקבילה ל־`npm run dev` עלתה ב־3231 עם מאגר Developer-Local חדש וריק וממשק Vite המשולב ב־Express.
- מסמך TXT חדש עם תוכן דמה הועלה דרך API האמיתי. נוצרו קטע אחד ווקטור אחד, עבודת האינדוקס וניתוח AI הסתיימו, ונוצרו חמישה קשרי AI לא מאומתים.
- השאלה ״מי אחראי על הכספים?״ הפיקה תשובת מודל ״מיכל ישראלי אחראית על הכספים״, עם מקור וציטוט מהקובץ. נרשמה תגובת Ollama אמיתית; מספר קריאות המודל בצ׳אט היה שתיים. התוצאות ב־`validation.json`.
- תהליכי הבדיקה הופסקו; המאגר המקורי לא הועתק אל מאגרי הבדיקה ולא אופס. לא בוצעו בדיקות עומס או שינוי התנהגות בקוד המוצר.

## בעיה שהתגלתה, ולא תוקנה במשימת תיעוד

בניסיון הראשון, ״מי אחראי על הכספים באוריון בדיקות?״ החזירה no-sources למרות שהשם הופיע במסמך הבדיקה. התוצאה נשמרה ב־`validation-first-attempt.json` ואינה מסומנת כהצלחה.

בקוד `server/Services/AnswerContextService.ts`, בפונקציה `selectAnswerSources`, שאלה פיננסית עם ארגון מפורש עלולה להחליף חיפוש כללי ב־`organizationSources`. מאגר נקי עם מסמך רגיל אינו בהכרח מספק פרופיל ארגון מזוהה למסלול הזה. השאלה הכללית הצליחה. המדריך משתמש בשאלה שעברה את הבדיקה, אך הדבר אינו פותר או מסתיר את בעיית האחזור. תיקונה דורש משימה נפרדת.

## עדיין דורש אימות

- התקנה על מחשב Windows חדש, התקנת Git/Node/Ollama, clone אמיתי ו־npm ci מהאינטרנט: לא בוצעו. אין תיקיית .git/Remote בעותק שסופק, ולכן אין כתובת GitHub אמיתית להכניס למדריך.
- לא בוצעה סקירה מאושרת לפרסום של כלל המסמכים והדוחות. לא הועלו קוד או נתונים ל־GitHub ולא נוצר Release.
- לא נבנה או הותקן EXE חדש. לא נמצא מתקין מוכן ב־release. מסלולי Desktop והתקנה נבדקו בקוד בלבד במשימה זו; שם קובץ הפלט הצפוי נגזר מ־electron-builder.yml וגרסת package.json.
- לא נבדקו CPU בלבד, מחשב עם RAM מינימלי, כמה משתמשים או ביצועי מסמכים רבים. דרישות החומרה במדריך מסומנות כהערכות.
- לא בוצעה בדיקה עם רשת חיצונית מנותקת. המדריך כולל הוראות לבדיקה כזו ואינו מצהיר על אימות אופליין מלא.
- לא הורץ דפדפן לצפייה בגרף במסגרת בדיקה זו; יצירת נתוני הגרף אומתה דרך מצב המאגר. הצגה, בחירת צומת והמקורות בממשק דורשים את רשימת הקבלה הידנית.

`verify.mjs` הוא כלי האימות למשימה זו, לא שלב הכרחי להתקנת הפרויקט. הוא יוצר סביבת בדיקה חדשה ומצריך תלויות ומודלים זמינים; אין להשתמש בו במקום ניסיון התקנה אמיתי במחשב נוסף.
