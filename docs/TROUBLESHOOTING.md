# פתרון תקלות — Windows

הריצו מהשורש ב־PowerShell. שמרו מסמכים ואינדקסים קיימים; אין צורך למחוק DB או להריץ reindex כדי לתקן התקנה.

| תסמין | בדיקה ופתרון |
| --- | --- |
| Ollama אינו זמין | `Invoke-RestMethod http://127.0.0.1:11434/api/tags`; פתחו Ollama מתפריט Start או `ollama serve` אם אינו פועל. אין לעצור שירות משותף |
| מודל חסר | `ollama list`, ואז `ollama pull gemma3:4b` ו־`ollama pull embeddinggemma`; בדקו התאמה ל־.env ול־settings.json ב־Desktop |
| חיבור ל־Ollama נכשל | ודאו OLLAMA_URL מקומי ב־http וללא פרטי משתמש; כתובת שרת ארגוני מרוחק אינה נתמכת במדיניות הקיימת. בדקו שירות ומדיניות Firewall/IT בלי להשבית אבטחה |
| פורט תפוס / EADDRINUSE | `Get-NetTCPConnection -LocalPort 3210 -State Listen` מציג OwningProcess; `Get-Process -Id <PID>` מזהה אותו. עצרו רק מופע שלכם או שנו PORT ב־.env והפעילו מחדש. פתחו את הכתובת החדשה. אין החלפת פורט אוטומטית בדפדפן |
| npm/node לא מוכרים | פתחו חלון חדש אחרי התקנה; בדקו `Get-Command node,npm`. אם npm.ps1 נחסם במדיניות, נסו `npm.cmd ci` ו־`npm.cmd run dev` או פנו ל־IT; אין צורך לשנות ExecutionPolicy לכל המחשב |
| npm ci / npm install נכשל | בדקו Node 22.x, מקום בדיסק וגישת רשת ל־npm ולהורדות Electron; השתמשו בהגדרות proxy ארגוניות מאושרות. `npm cache verify`; בדקו את שגיאת ההורדה המקורית. אין להשבית TLS או למחוק lockfile כפתרון ראשון |
| שגיאת node:sqlite | Node ישן או שונה ב־PATH: `node --version`, `Get-Command node`; השתמשו בסביבת 22.x שנבדקה. אזהרת ExperimentalWarning לבדה אינה כשל |
| ממשק לא נפתח | ודאו שהשרת עדיין פועל ושהכתובת תואמת PORT. Frontend ו־API באותו שרת; אין להריץ Vite בנפרד. ב־production דרוש dist שנוצר ב־npm run build |
| הממשק עולה אך שאלה נכשלת | בדקו את השדות בתוך `/api/health`, לא רק סטטוס HTTP. 503 OLLAMA_UNAVAILABLE מציין כשל מודל; 429 מציין עומס/בקשה מתחרה; 502 LOCAL_AI_INVALID_RESPONSE מציין פלט הבנת שאלה לא תקין. אין תשובה חלופית מוסתרת |
| Embeddings נכשל | בדקו embedding.available, שם מודל ושירות. RAG_EMBED_MODEL ריק משבית סמנטיקה ואינו פתרון קבוע. אין להחליף מודל על וקטורים קיימים בלי תוכנית מעבר נפרדת |
| מסמך נשאר בתור | ודאו BRAIN_PAUSE_BACKGROUND=0; בדקו `/api/jobs/summary`, ספריית מסמכים ושגיאה לכל מסמך. PDF סרוק דורש OCR שאינו ממומש. ודאו קובץ נתמך, תקין וללא הצפנה |
| המסמך ready אך AI נכשל | אינדוקס וניתוח גרף הם שלבים נפרדים. בדקו aiStatus/aiError בספרייה ו־Ollama. לגרף אין retry אוטומטי חדש; אפשר להפעיל חילוץ שוב דרך הפעולה בממשק לאחר תיקון התקלה |
| מסד אינו נוצר | בדקו BRAIN_DATA_DIR, הרשאות כתיבה ומקום. dotenv נקרא מתיקיית העבודה; משתני PowerShell קיימים גוברים עליו. נסו תיקייה חדשה נפרדת בבעלות המשתמש, בלי להעביר או לאפס את המאגר הקיים |
| Repository name does not match | BRAIN_REPOSITORY_NAME אינו תואם לשם שנשמר באותה תיקייה. חזרו לשם המקורי או בחרו תיקייה חדשה ושם חדש יחד; אין לערוך metadata כדי לעקוף |
| אין מסמכים אחרי התקנה | תקין עם BRAIN_SEED_DEMO=0; העלו מסמך בדיקה לפי המדריך. המאגרים המקומיים אינם נכללים ב־Git |
| שגיאת seed או knowledge_graph.json חסר | ודאו BRAIN_SEED_DEMO=0 בסביבת הפיתוח הריקה; אין צורך בקבצי seed. בניית מתקין עדיין מצפה למשאבי extraResources לפי electron-builder.yml |
| גרף ריק | בחרו מסמך או חפשו במפה; בדקו שהניתוח הסתיים ושיש קשרים. אין להמציא קשר כדי למלא את התצוגה |
| המודל איטי / RAM גבוה | בדקו `ollama ps` ו־Task Manager. CPU בלבד איטי יותר; ניתוח מסמכים ארוכים דורש קריאות רבות. הגבילו עבודה מיותרת ובדקו מסמך אחד לפני יבוא רחב. אין כאן אישור לביצועים או למקביליות של עשרה משתמשים |
| Desktop לא עולה / חסימה | עיינו ב־`%APPDATA%/DemoTech Knowledge Brain/logs/desktop.log` וב־settings.json. לפרופיל מותאם עיינו בנתיב שבחרתם. חסימת קובץ לא חתום דורשת IT או חתימה מאושרת, לא עקיפת הגנות |

לוגים זמניים: `BRAIN_TRACE_AI=1`, הפעלה מחדש ושאלה אחת. צפו ב־requestId, מודל, HTTP, זמן ו־receivedContent; אין צורך לרשום Prompts או טקסט ארגוני. אל תעלו דוחות אבחון למאגר ציבורי ללא סקירה. אחרי האבחון כבו את הדגל.

בבדיקת ההתקנה המקורית ״מי אחראי על הכספים באוריון בדיקות?״ לא מצאה מקור בגלל מסלול פיננסי שהחליף חיפוש בזיהוי פרופיל. בעדכון הצ׳אט שלאחר התיעוד הוסר מסלול זה; השאלה ״מי אחראי על הכספים בארגון״ נבדקה מחדש מול מאגר DemoTech. דוח ההתקנה נשמר כתיעוד היסטורי; בדיקת אוריון המפורשת דורשת הרצה חוזרת לפני שמסמנים אותה כמתוקנת.

לשלבי התקנה וקבלה: [INSTALL-WINDOWS.md](INSTALL-WINDOWS.md).
